# Cómo contribuir

Gracias por tu interés en mejorar uTV.

## Reportar un problema

- Usa la plantilla correspondiente al crear un issue.
- Para canales caídos, incluye el nombre del canal y el país.
- Para bugs, incluye la versión de la app, el dispositivo y los pasos para reproducirlo.

## Proponer cambios

1. Haz fork del repositorio.
2. Crea una rama descriptiva: `feat/nueva-funcion` o `fix/nombre-del-bug`.
3. Haz commits semánticos: `feat:`, `fix:`, `ui:`, `refactor:`.
4. Envía un Pull Request con una descripción clara de qué cambia y por qué.

## Reglas de código

- Kotlin con convenciones oficiales.
- Comentarios y comunicación en español, código en inglés.
- Reutiliza componentes existentes en `ui/components` antes de crear nuevos.
- No subas claves, keystores ni archivos de configuración local.
